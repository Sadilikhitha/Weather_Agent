## 🌤️ About SkyCast

**SkyCast** is an AI-powered weather intelligence platform that combines real-time weather information with Generative AI to provide conversational, context-aware weather insights and practical recommendations.

Users can interact with SkyCast using natural-language questions such as:

> ☔ **"Should I carry an umbrella?"**

> 🏃 **"Is it too hot for a run?"**

> 👕 **"What should I wear today?"**

> 🌧️ **"Will it rain today?"**

SkyCast combines live weather data, a FastAPI backend, LangChain, and Google Gemini to transform raw weather information into easy-to-understand recommendations.
